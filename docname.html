Front Inbox AI Reader

This version connects to a real Front inbox through the Front Core API, lets you load recent conversations, pulls the messages for the selected thread, and sends the thread content to OpenAI for summaries, action items, and reply drafting.

Production note: Front API tokens and OpenAI API keys should be handled by your backend. This single-file demo is useful for prototyping the workflow, but a real app should proxy both APIs server-side.
